# Personal Portfolio Website

A personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, and contact information.

## Features
- Introduction and About section
- Technical skills section
- Project showcase with GitHub links
- Contact and social links
- Responsive layout for mobile, tablet, and desktop
- Mobile navigation menu using JavaScript
- Smooth scrolling

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
my-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run Locally
1. Clone this repository.
2. Open the folder in VS Code.
3. Run `index.html` using Live Server.
